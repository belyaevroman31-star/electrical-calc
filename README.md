# Калькулятор электромонтажа — PWA

Прогрессивное веб-приложение для расчёта электроматериалов дома.

## Установка на GitHub Pages

1. Создайте репозиторий на https://github.com/new
2. Имя: `electrical-calc`
3. Загрузите все файлы из этой папки
4. Settings → Pages → Source: main branch
5. Приложение будет на: `https://ваш-логин.github.io/electrical-calc/`

## Установка на Android

1. Откройте ссылку в Chrome
2. Меню ⋮ → «Установить приложение»
3. Подтвердите установку

## Установка на iPhone

1. Откройте ссылку в Safari
2. «Поделиться» → «На экран Домой»
3. «Добавить»

## Возможности

- Работает офлайн
- Устанавливается на главный экран
- Сохраняет данные в localStorage
- Скачивание PDF и Excel
